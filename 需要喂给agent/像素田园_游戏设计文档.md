## 一、游戏概述 (Game Overview)

### 1.1 一句话描述
一款像素风休闲社交 farming 游戏——玩家在自己的田园里种植蔬菜，等待作物自然生长后收获，还可以拜访好友的房间"偷菜"，在轻松治愈的氛围中体验种植与社交的乐趣。

### 1.2 核心玩法循环
```
种植 → 浇水 → 等待生长（时间流逝）→ 收获 → 出售/储存 → 解锁新种子 → 装饰田园
         ↕                              ↕
   不浇水不生长                    隔天未收获则枯萎
              ↕
        拜访好友(最多2人同屏) → 偷菜（每次最多偷1/10，无防盗）→ 社交互动
```

> **核心决策说明**:
> - 浇水为必须操作，不浇水作物不会生长
> - 作物成熟后若自然时间隔天未收获，将会枯萎
> - 偷菜无防盗机制，仅受 1/10 规则和冷却时间限制
> - 好友拜访为轻度实时，最多 2 人同一画面

### 1.3 游戏支柱 (Game Pillars)
| 支柱 | 描述 |
|------|------|
| **治愈放松** | 低压力、无惩罚的休闲节奏，配合 Lo-fi 音乐和像素美学 |
| **社交互动** | 好友间的"偷菜"机制，轻量有趣，促进互动但不产生矛盾 |
| **收集成长** | 解锁新作物、装饰物品，打造个性化田园 |

### 1.4 目标用户
- Steam 平台休闲游戏玩家
- 喜欢模拟经营 / 种田类游戏的玩家
- 喜欢像素风、治愈系美术风格的玩家
- 有社交需求、喜欢和朋友轻度互动的玩家

## 二、交互设计 (Interaction Design)

### 2.1 操作方式
| 输入 | 操作 | 说明 |
|------|------|------|
| **鼠标左键** | 选择 / 确认 / 交互 | 点击土地、种子、作物、UI 按钮 |
| **鼠标右键** | 取消 / 返回 / 工具放下 | 退出当前操作状态 |
| **鼠标悬停** | 信息预览 | 悬停作物显示生长阶段、预计成熟时间 |
| **WASD / 方向键** | 角色移动 | 在房间和田园中移动角色 |
| **数字键 1-9** | 快捷栏切换 | 快速切换工具栏中的种子/工具 |
| **E 键** | 交互 | 与 NPC、好友房间入口、装饰物交互 |
| **ESC** | 打开主菜单 | 设置、存档、退出 |
| **Tab** | 打开背包/库存 | 查看种子、作物、道具 |
| **M 键** | 打开地图 | 查看可拜访的好友列表 |
| **滚轮** | 缩放视角 | 在田园场景中缩放查看细节 |

### 2.2 交互流程图

#### 种植流程
```
[选择种子] → [点击空地] → [播放种植动画] → [种子种下] → [等待浇水]
```

#### 浇水流程
```
[选择水壶] → [点击已播种土地] → [播放浇水动画] → [进入生长计时]
```
> 注: 不浇水则作物不会生长。每次浇水维持当前生长阶段推进，阶段切换后需再次浇水。

#### 收获流程
```
[点击成熟作物] → [播放收获动画] → [作物收入背包] → [土地变为可种植]
```
> 注: 作物成熟后若自然时间跨越次日零点仍未收获，将枯萎变为不可收获状态。

#### 枯萎流程
```
[成熟作物隔天未收获] → [播放枯萎变化] → [作物变灰/萎缩] → [点击清除] → [土地恢复空闲]
```

#### 偷菜流程
```
[打开好友列表] → [选择好友] → [进入好友房间] → [查看好友农田]
→ [点击成熟作物] → [计算可偷数量(总量×1/10)] → [播放偷菜动画]
→ [作物收入背包] → [好友收到通知]
```

### 2.3 UI 交互层级
```
Level 1 - 游戏场景 (Gameplay HUD)
  ├── 左上角：时间 / 天气 / 季节
  ├── 右上角：背包快捷栏 (1-9格)
  ├── 左下角：角色状态 (精力值 — 可选)
  └── 右下角：交互提示 (E键提示等)

Level 2 - 功能面板 (点击按钮弹出)
  ├── 背包/库存 (Tab)
  ├── 好友列表 / 地图 (M)
  ├── 商店 / 种子目录
  └── 装饰 / 布置模式

Level 3 - 系统菜单
  ├── 设置 (画面、声音、控制)
  ├── 存档管理
  └── 退出游戏
```

| **个人田园** | 玩家的核心种植区域 | 30×20 | 种植、浇水、收获 |

### 3.2 场景美术规范

#### 像素分辨率
- **场景 Tile 大小**: 16×16 像素/格
- **场景基础分辨率**: 480×320 (30×20 Tile)
- **角色 Sprite 大小**: 32×48 像素 (2×3 Tile)
- **支持缩放**: 2x (640×480), 3x (960×720), 4x (1280×960)

- **主色调**: 暖色调为主，偏 Lo-fi 复古感

- **光影**: 柔和的像素光影，模拟自然光变化
- **时间变化**: 昼夜循环影响场景色调（晨→午→昏→夜）

## 四、人物设计 (Character Design)

**外观**:
- **像素尺寸**: 32×48 像素
- **风格**: Q版像素小人，头身比约 1:2
- **默认造型**: 戴草帽、穿背带裤的小农夫

**自定义选项**:
- 发型 (6款): 短发、长发、双马尾、丸子头、爆炸头、光头
- 肤色 (4色): 浅白、小麦、棕褐、深色
- 服装 (多套解锁):
  - 默认农夫装
  - 休闲T恤
  - 礼服 (特殊场合)
  - 睡衣
  - 季节性服装 (春节、万圣节等)
- 配饰: 眼镜、帽子、围巾、背包

**角色属性**:
| 属性 | 说明 | 初始值 |
|------|------|:---:|
| 精力值 | 每次种植/收获消耗 1 点 | 100 |
| 精力恢复 | 每秒恢复 0.5 点 / 睡觉满值 | — |
| 背包容量 | 可携带物品数量 | 20 格 |
| 移动速度 | 场景内移动速度 | 标准 |

### 4.2 NPC 角色

### 4.3 好友角色

- 在线状态: 🟢 在线 / ⚪ 离线
- 拜访时好友角色可能出现在其房间中 (在线时)

## 六、作物系统 (Crop System)

### 6.1 作物基础数据

| 作物 | 种子价格 | 生长时间 | 收获价格 | 成熟外观 | 季节 |
|------|:---:|:---:|:---:|----------|------|
| 🥕 胡萝卜 | 10 | 30秒 | 25 | 橙色露出地面 | 春/秋 |
| 🍅 番茄 | 15 | 45秒 | 40 | 红色果实挂藤 | 夏 |
| 🥬 白菜 | 8 | 25秒 | 20 | 绿色大叶菜 | 秋/冬 |
| 🌽 玉米 | 20 | 60秒 | 55 | 高大植株带玉米棒 | 夏 |
| 🥔 土豆 | 12 | 40秒 | 30 | 地面绿叶茂盛 | 春/秋 |
| 🍓 草莓 | 25 | 50秒 | 65 | 红色小果贴地 | 春 |
| 🌶️ 辣椒 | 18 | 55秒 | 45 | 红色/绿色尖椒 | 夏 |
| 🎃 南瓜 | 35 | 90秒 | 90 | 大型橙色南瓜 | 秋 |
| 🍆 茄子 | 22 | 65秒 | 50 | 紫色长茄子 | 夏 |
| 🥦 西兰花 | 28 | 70秒 | 60 | 绿色花球 | 春/秋 |

> **注**: 游戏内时间为加速时间，1现实分钟 ≈ 游戏内1小时。以上生长时间为游戏内时间。

### 6.2 作物生长阶段
每种作物有 **5 个状态**（4 个生长阶段 + 1 个枯萎状态），每个阶段有独立的像素 Sprite:

```
阶段0: [种子/待浇水] → (浇水) → 阶段1: [发芽] → (浇水) → 阶段2: [生长中] → (浇水) → 阶段3: [成熟可收获] → (隔天未收获) → [枯萎]
```

| 阶段 | 视觉表现 | 占比 | 交互 | 浇水需求 |
|------|----------|:---:|------|:---:|
| **种子** | 土壤上小凸起 | 25% | 不可收获 | 需浇水才进入下阶段 |
| **发芽** | 小嫩芽破土 | 25% | 不可收获 | 需浇水才进入下阶段 |
| **生长中** | 植株明显长大 | 25% | 不可收获 | 需浇水才进入下阶段 |
| **成熟** | 果实/蔬菜可见，发光提示 | 25% | ✅ 可收获 | 无需浇水 |
| **枯萎** | 作物变灰/萎缩 | — | ❌ 仅可清除 | — |

**浇水机制**:
- 每个生长阶段切换都需要玩家手动浇水
- 浇水后进入计时，到达时间自动切换至下一阶段（再次需要浇水）
- 不浇水则作物停留在当前阶段，不会生长

**枯萎机制**:
- 作物进入「成熟」阶段后，若自然时间跨越次日零点（隔天）仍未收获，则进入枯萎状态
- 枯萎的作物无法收获，只能点击清除（恢复土地为空闲状态）
- 枯萎不扣经验、不扣金币，属于软惩罚（仅损失该次收益）

### 6.3 偷菜规则

```
可偷数量 = floor(好友该作物成熟总量 × 1/10)
```

**示例**:
- 好友田里有 23 个成熟番茄
- 可偷数量 = floor(23 × 0.1) = floor(2.3) = **2 个番茄**
- 好友剩余 = 23 - 2 = 21 个

**规则**:
1. 只能偷 **成熟** 的作物
2. 每种作物独立计算 (偷番茄不影响白菜)
3. 每次拜访每种作物最多偷一次
4. 被偷者会收到 **通知消息** (无惩罚)
5. 偷菜者需要 **进入好友房间** 后才能操作
6. 同一好友每 **15分钟** 只能偷一次
7. 被偷不影响好友的好友关系值
8. **无任何防盗机制** — 不设篱笆等级、看门狗等反制措施，保持社交轻松无压力

### 11.2 核心技术模块
```
Godot 4.4 项目
├── Scene Manager (场景管理 / SceneTree)
│   ├── RoomScene (房间)
│   ├── FarmScene (田园)
│   ├── ShopScene (商店)
│   └── PlazaScene (广场)
├── Character Controller (角色控制)
│   ├── Movement (移动)
│   ├── Animation (动画状态机 / AnimatedSprite2D)
│   └── Interaction (交互)
├── Crop System (作物系统)
│   ├── CropData (作物数据表 / Resource)
│   ├── GrowthTimer (生长计时器 / 时间戳)
│   ├── WaterManager (浇水管理) ← 新增
│   ├── WiltManager (枯萎管理) ← 新增
│   └── HarvestManager (收获管理)
├── Social System (社交系统)
│   ├── FriendManager (好友管理)

│   ├── StealManager (偷菜逻辑 / 无防盗)
│   └── P2PSync (Steam P2P 实时同步) ← 新增

├── UI Manager (UI管理 / Control节点)
├── Audio Manager (音频管理 / AudioStreamPlayer)
├── Save/Load System (存档系统 / JSON + Steam Cloud)
└── Steam Integration (GodotSteam 插件)
    ├── Steam Auth (登录)
    ├── Steam Friends (好友列表)
    ├── Steam Cloud (云存档)
    ├── Steam P2P Networking (轻度实时同步)
    └── Steam Achievements (成就)
```

### 11.3 数据存储
| 数据类型 | 存储方式 | 同步 |
|----------|----------|------|
| 玩家数据 (等级、金币) | 本地 JSON + Steam Cloud | 云端同步 |
| 作物数据 (种植时间、状态) | 本地 JSON + 时间戳 | 按需同步 |
| 好友列表 | Steam Friends API | 实时 |
| 好友田园数据 | Steam P2P 直连 | 拜访时实时同步（最多2人） |
| 装饰/布置 | 本地 JSON + Steam Cloud | 云端同步 |

### 11.4 时间系统实现
- 作物生长使用 **真实时间 + 时间戳** 存储
- 种子种下时记录 `plant_timestamp`
- **浇水时记录 `water_timestamp`**（浇水后才开始计时）
- 阶段切换条件: `current_timestamp >= water_timestamp + stage_duration`
- 阶段切换后需再次浇水，否则停留在新阶段不继续生长
- **枯萎条件**: 作物处于「成熟」状态时，若 `current_date > mature_date`（跨越零点），标记为枯萎
- 离线处理: 玩家离线后重新上线，检查时间差：
  - 已浇水的阶段正常推进
  - 未浇水的阶段保持不动
  - 成熟超过一天的标记枯萎
- 时间加速比: 1现实分钟 ≈ 游戏内1小时 (可配置)
