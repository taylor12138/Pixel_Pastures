# 《像素田园》PRD 拆分大纲

> **拆分原则**: 按「是否依赖美术资产」和「系统耦合度」拆分，优先开发纯逻辑/数据层

## PRD 详细列表

### 🟢 第一层: 纯逻辑/数据层 (零美术、零 UI 依赖)

| PRD | 名称 | 核心内容 | 美术需求 | 依赖 |
|:---:|------|---------|:--------:|------|
| **1** | **项目骨架 + 核心数据系统** | Godot 项目创建、目录结构、project.godot 配置、InputMap、全局单例框架、crops.json 数据加载 | ❌ 无 | 无 |
| **2** | **作物生长状态机 + 浇水/枯萎** | 作物 5 状态机、浇水触发生长、时间戳计时、枯萎判定（隔天零点）、阶段切换信号 | ❌ 无 | PRD1 |
| **3** | **背包/库存系统 (数据层)** | 物品数据结构、增删改查、容量限制(20格)、堆叠规则、快捷栏映射 | ❌ 无 | PRD1 |
| **4** | **经济系统 + 商店逻辑** | 金币增减、种子购买/作物出售逻辑、价格表、交易验证 | ❌ 无 | PRD1, PRD3 |
| **5** | **等级/经验/解锁系统** | 经验获取规则、升级判定、解锁内容管理、种子/功能解锁条件查询 | ❌ 无 | PRD1 |
| **6** | **存档系统** | JSON 序列化/反序列化、自动存档、手动存档、多存档槽、存档数据结构定义 | ❌ 无 | PRD1-5 |
| **7** | **游戏时间系统** | 游戏内时间流逝(1实分钟=1游戏时)、昼夜周期、季节轮换、日期跨越检测(枯萎用) | ❌ 无 | PRD1 |

## 建议开发顺序

```
Week 1-2:   PRD1 → PRD7 → PRD2           (数据基础 + 时间 + 作物状态机)
Week 3-4:   PRD3 → PRD4 → PRD5 → PRD6    (背包/经济/等级/存档)
Week 5-6:   PRD8 → PRD9 → PRD10          (场景/移动/交互闭环 — 可玩原型!)
Week 7-8:   PRD11 → PRD12 → PRD13 → PRD14 (UI 面板)
Week 9-10:  PRD15 → PRD16 → PRD17 → PRD18 → PRD19 (美术/音频接入)
Week 11-14: PRD20 → PRD21 → PRD22 → PRD23 → PRD24 (社交/网络)
Week 15-16: PRD25 → PRD26 → PRD27 → PRD28 (打磨)
```

**🎯 里程碑节点**:
- **Week 6 结束**: 纯逻辑可玩原型（色块版），核心循环跑通
- **Week 10 结束**: 完整单人体验（含美术），可内测
- **Week 14 结束**: 社交功能完成，可 Beta 测试
- **Week 16 结束**: 全功能完成，准备上架
