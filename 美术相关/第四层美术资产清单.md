# 《像素田园》第四层美术资产清单

> **范围**: PRD15 ~ PRD19（角色动画 / 作物视觉 / 场景美术 / 特效粒子 / 音频）
> **用途**: 供美术按此清单制作素材，制作完成后按"存放路径"放入工程
> **引擎**: Godot 4.x（项目 `pixel-farm/`）
> **最后更新**: 2026-06-11

---

## 〇、通用技术规范（所有素材必读）

| 项 | 规格 |
|------|------|
| Tile 网格 | **16×16 px / 格** |
| 场景基础分辨率 | **480×320**（30×20 Tile），整数倍缩放 2x/3x/4x |
| 角色 Sprite | **32×48 px**（2×3 Tile），头身比约 1:2 |
| 角色 Sprite Sheet | 统一 **256×256 px / Sheet** |
| 动画帧率 | **12 fps**（复古，默认）/ 可切 24 fps |
| 每动作帧数 | 4–8 帧（偷菜 steal 例外 10 帧） |
| 文件格式 | **PNG，32 位带透明通道**；像素硬边、**禁止抗锯齿/羽化** |
| 调色板 | 暖色调 Lo-fi 复古；**每场景 32–48 色以内** |
| 导出方式 | Sprite Sheet 优先（横向排帧），单帧命名见各节 |
| 命名规范 | 全小写 + 下划线，与本清单内 ID 完全一致 |

> **重要**: 同一场景内复用调色板；昼夜色调（晨/午/昏/夜）通过引擎 tint/光照实现，美术只需提供"中午基准"版本（除非另注）。

## PRD16 · 作物 Sprite + 生长阶段视觉

存放路径：`pixel-farm/assets/sprites/crops/`
单帧规格：**16×16 px**（高大作物 玉米/番茄/南瓜 可用 16×32 px，底部对齐地块）

### 16.1 作物生长阶段（每种作物 5 张）

每种作物需 **5 个阶段 Sprite**，对应代码枚举 `SEED→SPROUT→GROWING→MATURE→WITHERED`：

| 阶段 ID | 视觉表现 | 可收获 |
|---------|----------|:---:|
| `stage_0_seed` | 土壤上小凸起 | ❌ |
| `stage_1_sprout` | 小嫩芽破土 | ❌ |
| `stage_2_growing` | 植株明显长大 | ❌ |
| `stage_3_mature` | 果实/蔬菜可见（需发光提示） | ✅ |
| `stage_4_withered` | 变灰/萎缩 | ❌（仅清除） |

**10 种作物 × 5 阶段 = 50 张作物 Sprite**：

| 作物 ID | 名称 | 成熟外观参考 |
|---------|------|------|
| `carrot` | 胡萝卜 | 橙色露出地面 |
| `tomato` | 番茄 | 红色果实挂藤（高） |
| `cabbage` | 白菜 | 绿色大叶菜 |
| `corn` | 玉米 | 高大植株带玉米棒（高） |
| `potato` | 土豆 | 地面绿叶茂盛 |
| `strawberry` | 草莓 | 红色小果贴地 |
| `pepper` | 辣椒 | 红/绿尖椒 |
| `pumpkin` | 南瓜 | 大型橙色南瓜（高） |
| `eggplant` | 茄子 | 紫色长茄子 |
| `broccoli` | 西兰花 | 绿色花球 |

命名示例：`carrot_stage_0_seed.png` … `carrot_stage_4_withered.png`

### 16.2 配套图标（背包 / 商店 / HUD 用）

| 类型 | 数量 | 规格 | 说明 |
|------|:---:|:---:|------|
| 种子图标 `seed_<crop>` | 10 | 16×16 | 商店/背包内种子物品 |
| 收获物图标 `crop_<crop>` | 10 | 16×16 | 成熟作物的物品图标 |

### 16.3 成熟发光提示

| ID | 说明 |
|----|------|
| `crop_mature_glow` | 成熟阶段叠加的发光/呼吸光晕（可单张通用，循环动画 4 帧） |

## 交付与对接说明

1. **优先级建议**：PRD16 作物 → PRD15 玩家基础动画（idle/walk/plant/water/harvest）→ PRD17 田园 TileSet → PRD19 田园 BGM/核心 SFX → PRD18 核心特效 → 其余社交/环境/NPC 资产。
2. **命名严格对齐**本清单 ID；Sprite Sheet 横向排帧，附帧数说明。
3. **放置路径**已与工程 `pixel-farm/assets/` 目录结构一致，制作完成直接入库即可。
4. 范围内**不含** PRD11–14 正式 UI 皮肤、PRD28 动物伙伴、PRD27 公共广场场景美术（属其他层级，后续单列）。
