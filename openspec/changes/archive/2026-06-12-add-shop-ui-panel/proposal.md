## 为什么

PRD4 已提供完整的购买、出售、价格查询和交易校验数据层，但玩家目前缺少正式 UI 来完成经济循环。现在需要将这些能力接入可操作的商店面板，使玩家能够查看商品与解锁状态、选择数量并获得明确的交易反馈。

## 变更内容

- 新增基于 Godot `Control` 节点的商店主面板和可复用商品行组件。
- 提供购买与出售双 Tab，分别展示可购买商品和背包内可售收获物。
- 提供商品详情、当前金币、拥有数量、解锁等级、数量预设、最大可交易数量和总价展示。
- 所有交易预校验与提交统一调用 `EconomyManager`，UI 不直接修改金币、库存、价格或解锁数据。
- 交易完成后通过事件驱动方式刷新余额、商品行、库存数量和可交易状态，并对失败原因给出明确反馈。
- 面板打开期间阻止角色移动、农田点击、交互键和调试输入穿透，但默认不暂停游戏时间。
- 扩展 `EventBus`，广播商店面板开关、Tab 切换、商品选择和数量变化事件。
- 新增可独立运行的商店 UI 测试场景，覆盖列表、选择、数量、交易、解锁刷新和输入阻塞等关键行为。

## 功能 (Capabilities)

### 新增功能

- `shop-ui`: 定义商店面板的开关、购买/出售列表、商品详情、数量选择、交易提交、结果反馈、事件刷新、输入阻塞和测试要求。

### 修改功能

- `event-bus`: 增加商店面板状态、Tab、选中商品和数量变化的跨系统事件契约。

## 影响

- **新增文件**: `scenes/ui/shop/shop_panel.tscn`、`scenes/ui/shop/shop_item_row.tscn`、`scripts/ui/shop/shop_panel.gd`、`scripts/ui/shop/shop_item_row.gd`、商店挂载场景及测试场景。
- **修改文件**: `scripts/autoload/event_bus.gd`，以及用于挂载商店面板或临时入口的场景与控制脚本。
- **依赖系统**: `EconomyManager`、`InventoryManager`、`LevelManager`、`GameManager`、`DataManager`、`EventBus`。
- **运行行为**: 新增一套全屏功能面板；不改变现有经济交易规则、价格表、库存权威边界和解锁规则。
